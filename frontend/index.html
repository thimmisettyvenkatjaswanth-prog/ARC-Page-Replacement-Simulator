1. What is ARC?

Adaptive Replacement Cache (ARC) dynamically balances recency and frequency in real time without manual tuning. Traditional LRU can be severely degraded by one-off sequential scans, while pure LFU accumulates stale "zombie" pages. ARC delivers the advantages of both.

💾

2. Resident Lists T1 & T2

Cache memory capacity c is split between two resident page lists:

  • T1 (Recency): Resident pages accessed only once recently.
  • T2 (Frequency): Resident pages accessed at least twice (high reuse).

Invariant: |T1| + |T2| ≤ c

👻

3. Ghost Lists B1 & B2

Ghost caches store only metadata (page identifiers) without page contents:

  • B1: Remembers pages recently evicted from T1.
  • B2: Remembers pages recently evicted from T2.

A hit in a ghost cache indicates that increasing the respective list's target size would have prevented a cache miss!

⚙

4. Adaptive Parameter p

Parameter p ∈ [0, c] represents the target size of recency cache T1.

  • B1 Hit (Needs Recency): Shifts p upwards by δ1 = max(1, |B2|/|B1|).
  • B2 Hit (Needs Frequency): Shifts p downwards by δ2 = max(1, |B1|/|B2|).

When a sequential scan occurs, pages populate T1 without polluting T2.

Replacement Policy Primary Metric Scan Resistance Frequency Awareness Tuning Overhead
ARC (Adaptive Replacement Cache) Dual Recency + Frequency with Ghost Memory High (Auto-shields T2) High (Tracks repeated hits) None (Online Self-Tuning)
LRU (Least Recently Used) Pure Recency Poor (Vulnerable to Scans) None (Equal weight for all hits) None
FIFO (First-In, First-Out) Pure Arrival Order Poor (Prone to Belady's Anomaly) None (Hits do not update order) None
